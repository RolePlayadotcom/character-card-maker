Character Card Maker

Write an AI character, add a picture and download it as a PNG character card or a JSON file. Cards follow the V2 and V3 specs, so they import straight into RolePlaya and open in SillyTavern, Chub, RisuAI and most other apps. You can also open an existing card to edit it. Everything happens in your browser; nothing is uploaded.

The PNG card carries both V2 and V3 data, the same way SillyTavern saves cards, so older and newer apps can both read it. Lorebooks and extension data from a card you opened are kept. Token counts are estimates; each app counts slightly differently.

Made by RolePlaya, the AI roleplay platform for adults, which imports V2 and V3 cards directly. Check a card with the Character Card Checker. How to import character cards. Open source under the MIT licence.
